Academic Syllabus & Units

B.Tech Computer Engg · Sem VI

DBATU Curriculum · 22 Credits Total

Compiler Design (CS601)

Theory: 3 Hrs/Week · ISE: 20 · ESE: 80

4 Credits
Unit 1: Introduction to Compiler structure, Lexical Analysis, Regular Expressions, Finite Automata, LEX/FLEX tool.
Unit 2: Syntax Analysis, Context-Free Grammars, Top-Down Parsing (LL(1)), Bottom-Up Parsing (LR, SLR, CLR, LALR), YACC tool.
Unit 3: Syntax-Directed Translation, Attribute Grammars, Intermediate Code Generation (Three-Address Code, Quadruples, Triples).
Unit 4: Code Optimization: Basic Blocks, Flow Graphs, Loop Invariant Code Motion, Dead Code Elimination, Peephole Optimization.
Unit 5: Code Generation & Runtime Storage Administration: Symbol Table Management, Register Allocation, Target Machine Code.
Data Science & Artificial Intelligence (CS602)

Theory: 3 Hrs/Week · ISE: 20 · ESE: 80

4 Credits
Unit 1: Data Science Pipeline, Data Cleaning, Wrangling, Exploratory Data Analysis with Pandas, NumPy and Matplotlib.
Unit 2: Supervised Learning: Linear Regression, Logistic Regression, Decision Trees, Random Forests, Support Vector Machines.
Unit 3: Unsupervised Learning & Clustering: K-Means, Hierarchical Clustering, Principal Component Analysis (PCA).
Unit 4: Artificial Intelligence & Neural Networks: Multi-Layer Perceptrons, Backpropagation, Gradient Descent optimization.
Unit 5: Deep Learning & Real-world Applications: CNNs for Computer Vision, RNNs for Text, Model Evaluation Metrics.
Web Technologies (CS604)

Theory: 3 Hrs/Week · Practical: 2 Hrs/Week

4 Credits
Unit 1: Modern HTML5, Semantic Elements, CSS3 Grid, Flexbox, Responsive Design, CSS Variables.
Unit 2: JavaScript ES6+, Promises, Async/Await, DOM Manipulation, Fetch API, Modular JavaScript.
Unit 3: Front-End Frameworks: Component Architecture, React Hooks, State Management, Routing.
Unit 4: Back-End Development: Node.js runtime, Express RESTful APIs, Middleware, JWT Authentication.
Unit 5: Databases & Deployment: MongoDB, Mongoose ODM, MySQL Integration, Cloud Hosting (Vercel/Render).
Software Engineering & Agile (CS603)

Theory: 3 Hrs/Week · ISE: 20 · ESE: 80

3 Credits
Unit 1: Software Process Models, Agile Manifesto, Scrum Roles, Sprint Planning, Kanban Framework.
Unit 2: Software Requirements Specification (SRS), User Stories, UML Use Case, Sequence & Class Diagrams.
Unit 3: Software Architectural Patterns: Microservices, MVC, Design Patterns (Factory, Singleton, Observer).
Unit 4: Software Testing: Unit Testing, Integration, Black-Box & White-Box Testing, Test Automation with JUnit.
Unit 5: DevOps Principles, CI/CD Pipelines, Version Control with Git, Software Quality Metrics.
