## 🚀 Key Features

- **Instant Theme Switching:** Toggle via the top header button (cycles through all 4 themes), the side navigation drawer, or the student profile view.
- **Persistent State:** User's active theme is stored in `localStorage` and persists across page reloads.
- **6 Full Views:**
  1. 🏠 **Home Dashboard:** Quick stats, schedule, interactive attendance/timetable modals, circulars, and events.
  2. 📚 **Courses:** Course progress bars, faculties, and distinction badges.
  3. 🎉 **Events:** Filterable campus events (Cultural, Tech, Sports).
  4. 📅 **Academic Calendar:** Interactive timeline with exam dates and milestone badges.
  5. 👤 **Student Profile:** Digital student ID card with dynamic barcode and mentor info.
  6. ❓ **Help & Support:** 24/7 campus helplines, FAQ accordion, and query submission form.
- **PWA-ready & Responsive:** Beautiful mobile frame with status bar clock, glassmorphic bottom navigation, and fluid animations.
